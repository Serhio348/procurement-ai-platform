# STAGE-101 · Деталь всегда догружает полную карточку; тосты о перемещении (R50)

## Проблема

1. **«Документы (0)» до ручного «Обновить».** Список кабинета отдаёт
   slim-плитки: `tileCardExpression` в `specialist-store` вырезает
   `documents`, `actions`, `reportMarkdown` и т.п. из JSONB, чтобы страница
   в 100 карточек не тащила тяжёлые поля. `ProcurementDetailApp` брал
   `stored = fromList ?? fetched` и **не запрашивал** `fetchCase`, если
   плитка уже была в `procurements` — деталь рендерила урезанную карточку
   навсегда. «Обновить» чинило случайно: `reindex` возвращал полную
   карточку, которая мержилась в state списка.
   Тот же класс дефекта, что R49 (slim-проекция затирает богатую карточку),
   но на уровне списка → детали.

2. **Действия с карточкой проходили молча.** «Участвовать» убирает
   карточку из поисковой панели (она переезжает в «Мои закупки»), «Убрать»
   — в корзину. Пользователь видел только исчезновение.

## Решение

**Деталь.** `ProcurementDetailApp` всегда вызывает `fetchCase(id)` при
монтировании — это дешёвый `GET /api/procurements/:id` (SQL-read, без
живого обращения к площадке). `stored = fetched ?? fromList`: плитка —
мгновенный плейсхолдер, полная карточка приходит и выигрывает. Все
мутации (`runDecide`, `refreshCase`, ingest-done poll, `loadPlatformCard`)
обновляют `fetched`, чтобы источник истины не расходился. Эффект завязан
только на `id` через рефы — смена `fromList`/`onCardLoaded` не зацикливает
запрос.

**Тосты.** Переиспользован `NoticeStack` (passive toasts, 10 с
автоскрытие). `SpecialistApp` добавляет `pushNotice(title, message)` и
передаёт `notice` в `ProcurementsApp`, `ProcurementDetailApp`,
`MyProcurementsApp`. Сообщения:

| Действие | Тост |
|---|---|
| Участвовать | «Мои закупки» — участвуем, документы скачиваются |
| Отслеживать | «Мои закупки» — отслеживаем изменения |
| Не нужно / Убрать | «Корзина» — перемещена в корзину |
| Вернуть из корзины | «Мои закупки» — возвращена из корзины |
| Удалить / очистить | «Корзина» — удалена безвозвратно / очищена |
| В архив / вернуть | «Архив»/«Мои закупки» — перемещена/возвращена |

Inline-нотисы поисковой панели сохранены — тост дополняет их, а не
заменяет.

## Регрессии

- `fetches the full case when the list tile carries no documents` —
  плитка с `documents: []` + `fetchCase` с полной картой → «Документы (1)»
  без «Обновить»;
- `announces where the card went when the specialist participates` —
  decide → `notice("Мои закупки", …участвуем…)`;
- полный файл `ProcurementDetailApp.test.tsx` 9/9, ProcurementsApp 23/23,
  MyProcurementsApp 30/30, notice-тесты 4/4.
