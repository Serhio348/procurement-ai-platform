# STAGE-104 · Модальное подтверждение удерживает фокус (R33)

Дата: 2026-05-06. Статус: выполнено.

## Проблема

`ConfirmToast` имел `role="alertdialog"`, `aria-modal` и `autoFocus` на «Отмена»,
но не удерживал фокус: Tab/Shift+Tab уходили на скрытые фоновые элементы,
после закрытия фокус терялся (activeElement → body), а не возвращался
на кнопку, открывшую диалог.

## Решение

- Focus trap: keydown на `window`; Tab от последнего контрола → первый,
  Shift+Tab от первого → последний; Tab при фокусе вне диалога → возвращает
  фокус внутрь. Список фокусируемых — стандартный селектор
  `button, [href], input, select, textarea, [tabindex]`, disabled отфильтрованы.
- Восстановление фокуса: открывающий элемент захватывается **во время первого
  рендера** (ref), потому что `autoFocus` срабатывает в commit-фазе раньше
  mount-эффектов — в эффекте `document.activeElement` уже «Отмена».
- Escape — по-прежнему `onCancel`; Enter — нативное поведение кнопок.
- `UnsavedGuard` использует нативный `window.confirm` — там trap встроенный,
  отдельной работы не требует.

## Проверка

- `ConfirmToast.test.tsx`: Tab/Shift+Tab циклится внутри диалога;
  после unmount фокус возвращается на открывшую кнопку.
