# Этап 112 — вкладки «Новые закупки» / «Изменения в моих закупках» во входящих (R63)

## Проблема

Входящие показывали две группы одна под другой: секция «Новые закупки», ниже «Изменения в моих закупках». При десятках записей специалисту приходилось прокручивать одну группу, чтобы добраться до другой — разделение было, но неявное.

## Решение

Группы превращены в переключаемые вкладки в тулбаре «Входящих»:

- `role="tablist"` «Разделы входящих» с двумя `role="tab"` кнопками: «Новые закупки (N)» и «Изменения в моих закупках (M)» — счётчики видны на самих вкладках;
- маппинг топиков: `new_found`, `review` → «Новые закупки»; `documents`, `card_update` → «Изменения в моих закупках»;
- по умолчанию активна «Новые закупки», если в ней есть записи, иначе — «Изменения»;
- при переключении вкладки выделяется первая запись группы (`onSelect`), детальная панель показывает запись только из активной группы — выбор из другой вкладки не «проваливается» в деталь;
- пустая вкладка показывает своё сообщение («Новых закупок нет» / «Изменений в отслеживаемых закупках нет»);
- «Очистить всё» (STAGE-111) по-прежнему разбирает все записи обеих вкладок;
- тач-цель вкладок ≥44px на ≤768px.

## Регрессии

- `InboxApp.test.tsx` «splits new procurements from changes on watched cards»: счётчики на вкладках, по умолчанию «Новые закупки», переключение скрывает/показывает соответствующие строки.
