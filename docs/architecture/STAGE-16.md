# Этап 16 — живой прогон одной закупки

**Статус:** с `goszakupki.by` взята первая процедура по ключевому слову
профиля (КТПБ / 2БКТПБ). Карточка, локальные копии PDF и цитата оплаты с
площадки показаны в консоли. Это не выгрузка всего сайта.

---

## 1. Цель

Показать специалисту один реальный кейс после вертикального прогона:
поиск → карточка → документы → условия → отчёт. Без чата и без оценки
моделью. Клик по PDF открывает сохранённую копию, а не повторную загрузку
с площадки.

## 2. Архитектурное решение

- CLI `npm run capture:live-case` ходит в live-адаптер, пишет
  `tests/fixtures/specialist/live-run.json` и байты в `data/blobs/{sha256}`.
  Каталог `data/` в git не входит.
- Консоль ходит в `GET /api/documents/:hash`. Отдаётся только hash,
  который есть у документа в каталоге. Чужой файл на диске не отдаётся.
- Это локальная копия для `npm run web` без Docker. Production-хранилище
  по-прежнему MinIO / `files.put`.
- `compileSpecialistCase` в domain собирает карточку: cheap classify,
  cheap extract только при цитате «аванс N%», отчёт кодом, score не
  считается.
- API при старте поднимает snapshot в каталог. Verify не требует сети:
  снимок уже в fixture. Наличие байт на диске для CI не обязательно.

## 3. Почему именно так

Живой поиск в UI-кнопке ещё не оркестратор. Снимок фиксирует прогон,
чтобы консоль не зависела от площадки при каждом `npm run web`. Ссылка
на goszakupki.by при каждом клике заново качает PDF и зависит от сессии
площадки — для специалиста это лишний риск и лишний трафик.

## 4. Изменения

- capture пишет content-addressed копии;
- Fastify отдаёт PDF inline;
- карточка Закупки ссылается на `/api/documents/{hash}`, если hash есть.

## 8. Контракты API / MCP / агентов

HTTP:

- `GET /api/documents/:hash` — `application/pdf` (или octet-stream),
  `Content-Disposition: inline`. 400 / 404, если hash невалиден, не в
  каталоге или файла нет.

Новых MCP tools нет. Document MCP `files.put` не вызывается из консоли.

## 9. Тесты

- API отдаёт только blob из каталога;
- файл на диске без записи в каталоге — 404;
- hashed документ в UI ведёт на `/api/documents/{hash}`.

## 10. Риски и ограничения

1. `data/blobs` нужно заполнить `npm run capture:live-case` на машине
   с доступом к площадке. Без байт API отвечает `blob_missing`.
   `LIVE_CASE_SOURCE_ID=auction/3629820` фиксирует тот же кейс, иначе
   первый хит поиска меняется.
2. Текст PDF по-прежнему не извлечён: коммерческие условия с карточки
   площадки, не из файла.
3. MinIO не подключён. Смена каталога на S3 — отдельный шаг.

## 11. Критерии приёмки

- [x] в списке есть живая 2БКТПБ с ссылкой goszakupki.by;
- [x] документы hashed;
- [x] клик по PDF открывает локальную копию;
- [x] 99,5% предоплаты не стали полем «аванс» без шаблона;
- [x] `npm run verify` без Docker.
