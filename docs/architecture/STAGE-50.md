## Разметка

Профиль: поставка / изготовление **НКУ для управления насосами**.

- `relevant` — объект и тип закупки совпадают с профилем;
- `irrelevant` — мусор площадки или шкаф не про насосы;
- `uncertain` — без документов неясно (общее НКУ 0,4 кВ; очистные + монтаж;
  «Шкаф автоматики» без объекта).

Неуверенные в Precision / Recall / F1 не входят.

## Ошибки нового поиска

False positives:

- `single-source/3664623` — шкаф управления **наружным освещением**, score 60;
- `request/3645949` — шкаф управления **котельной**, score 90 (`поставщика` =
  desired «поставка»).

False negatives: нет.

Сильный сдвиг score / решения: veto монтажа/ремонта/ПНР (seed); «Изготовление
шкафа управления насосами» old=review → new=match 90; очистные
`marketing/3616560` old=match → new=review 50.

Старый поиск ошибается из‑за одного слова: «Монтаж/Ремонт/Пусконаладка НКУ»;
НКУ только в extra; плюс те же два шкафа не про насосы. FN старого:
«Изготовление шкафа управления насосами» — фраза «шкаф управления» не ловит
«шкафа».

## Анализ

Новый отбор лучше режет работы как предмет закупки. На живых данных его
ломают **чужие шкафы управления** и то, что score 0 без объекта всё равно
уходит в **review** (очередь «конкурсов»). Площадка по «НКУ» почти не
возвращает целевые карточки — сначала нужно чистить запрос к источнику.

Веса под этот dump **не подгонялись**.
