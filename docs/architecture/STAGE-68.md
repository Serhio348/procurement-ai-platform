# Этап 68 — «включая» помечает второстепенную клаузу, а не отменяет veto (R08)

## Цель

`SIDE_MENTION` срабатывал на маркер `включая` / `в том числе` / `с последующим`
в любом месте заголовка и понижал **все** исключённые действия до `mention`.
«Монтаж НКУ, включая поставку крепежа» получал `match` 80 для профиля
поставки: veto на монтаж отключался, хотя монтаж — настоящий предмет, а
второстепенна именно клауза после маркера (поставка крепежа).

Цель: маркер действует на то, что стоит после него, а не на весь заголовок.

## Архитектурное решение

1. `splitIntentClauses` делит заголовок на предложения, а каждое предложение —
   на основную часть и второстепенную (от маркера до конца предложения).
2. `включая` / `в том числе` / `с последующим` — маркеры «вперёд»: второстепенно
   то, что следует за ними. Исключённый глагол только во второстепенной части →
   `mention`; в основной — обычный разбор (`subject` / `peer` / `mention` по
   позиции относительно желаемого).
3. `силами заказчика` — маркер «назад»: понижает глагол, за которым стоит в том
   же предложении («Поставка НКУ, монтаж силами заказчика» — поставка остаётся
   предметом).
4. Проверка `peer` (равноправное перечисление поставки и работ) ведётся только
   по основной части — клауза после «включая» не создаёт ложный смешанный
   предмет.
5. Мёртвая ветка (`WORK_LEAD` / `purchaseWorkHead` / `startsWithTerm`, оба
   исхода — `subject`) удалена; желаемые действия и объекты по-прежнему ищутся
   по всему заголовку — veto решает роль исключённого действия, а не веса.
6. `REVIEW_ALGORITHM_VERSION` → `search-review-v6`: автоматические вердикты
   алгоритма, слепого к области маркера, пересматриваются.

## Тесты

- «Монтаж НКУ, включая поставку крепежа» → veto, excludedRole subject;
- то же с «в том числе» → veto;
- «Поставка НКУ, включая монтаж» → match, mention;
- «Поставка НКУ, монтаж силами заказчика» → match, mention;
- тот же заголовок для works-профиля → match;
- veto сохраняется на уровне карточки (`scoreSearchIntentFromProcedure`).

## Приёмка

- «Монтаж НКУ, включая поставку крепежа» — не match для поставки НКУ.
- «Поставка НКУ, включая монтаж» остаётся match.
- Evaluation: P/R/F1 = 100 %, FP=0, FN=0 — без регрессий.

## Риски и ограничения

- Желаемое действие пока не привязано к объекту: «Поставка крепежа, включая
  монтаж НКУ» для профиля поставки НКУ всё ещё может дать match — объект НКУ
  виден в заголовке. Это задача связывания действия с объектом (область R10).
- Больше veto направления mention→subject: часть карточек, ранее уходивших на
  review, теперь отсекается детерминированно. Осознанно — маркер раньше
  отключал veto без оснований.
