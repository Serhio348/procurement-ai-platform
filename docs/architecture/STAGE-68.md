# Этап 68 — универсальный отсев работ по предмету профиля

## Цель

Во «Входящих» копился общестрой по словам «СМР» / «пусконаладка» без предмета
профиля. Нельзя зашивать «энергетику» в код: платформа универсальна. Предмет
задаёт профиль; модель читает профиль целиком.

## Решение

1. **Код (works):** если в тексте нет объектов/`required_context` профиля и
   совпали только общие фразы работ (СМР, подряд, пусконаладка…) — **veto**,
   без модели. Если есть специфичная фраза профиля без объекта — **review**
   (модель).
2. **Модель:** relevant только по смыслу *этого* профиля (keywords/objects),
   не из‑за голых «СМР».
3. **UI профиля:** подсказка при фокусе на названии; поле «Для модели
   (направление)» пишется в `description` и уходит классификатору.
4. **«Исключать»** — только стоп-слова площадки, не промпт.
