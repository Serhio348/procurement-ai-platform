# Этап 69 — СМР по электрике доходит до модели в профиле работ

## Цель

Закупка вроде «строительно-монтажные работы … модернизация РЭС … замена
КРУН-10 кВ» не попадала ни в поставку (правильно — вето), ни в «Монтаж»:
площадка не находила её по фразам профиля, а код после `procurement.get`
ставил **veto** из‑за лота «Реконструкция…» и не звал модель.

## Живой прогон классификатора (до кода)

Модель уже видит имя, purpose и keywords профиля. На карточке Докшицы:

| Профиль | Вердикт модели | conf |
|---|---|---|
| Монтаж электросилового | **relevant** | 0.8 |
| КТПБ/КРУ (поставка) | needs_human (скорее работы) | 0.6 |
| Монтаж + зерно / котельная | needs_human | 0.6 |

Значит путь «найти → отдать модели» для работ оправдан.

## Решение

1. **Retrieval:** у `intent: works` с желаемым «монтаж» в `platformSearchTerms`
   добавляется синоним `строительно-монтажные работы`.
2. **Score:** `purchaseWorkHead` как исключение только для профилей поставки
   (`planAllowsBareObject`). Профиль работ не получает veto с лота
   «Реконструкция…», пока объект не назван — остаётся discard/review и
   вызывается классификатор.
3. Поставка без изменений: СМР с КРУ в названии по-прежнему veto.
