# Этап 70 — объект извлекается из фразы поставки и коротких обозначений (R10)

## Цель

Разбор ключевых фраз терял объект в двух случаях:

1. «поставка насосов» целиком уходила в `desired_actions` — `objects: []`.
   Карточка «Насос центробежный» получала `discard`: план не знал, какое
   оборудование ищет специалист.
2. `splitWorkPhrase` принимал объект только при длине ≥ 4: «монтаж КТП» →
   `objects: []`. «Монтаж котла» доходил до `review` по общему глаголу
   «монтаж», хотя предмет чужой и должен отсекаться `discard`.

Цель: одинаковое разложение «действие + объект» для фраз поставки и работ;
валидность объекта определяется не голой длиной.

## Архитектурное решение

1. `splitSupplyPhrase` — симметричный аналог `splitWorkPhrase`: токены —
   глаголы (supply-лексикон или работный) уходят в `actions`, оставшиеся
   существительные образуют `object`. Смешанная фраза «поставка и монтаж
   НКУ» даёт действия `[поставка, монтаж]` и объект `НКУ` — именно это
   специалист и имел в виду.
2. `plausibleObject` вместо `length >= 4`: объект принят, если длина ≥ 4
   **или** ≥ 2 и содержит заглавную букву/цифру. «КТП», «НКУ», «РП»,
   «КВр-0,5» — настоящие обозначения; строчный обрывок из 2–3 букв по-прежнему
   отбрасывается.
3. Токенизация фраз вынесена в общий `phraseTokens`.
4. Извлечённый объект попадает и в `platformSearchTerms` (bare-object для
   purchase-профилей) — retrieval получает дополнительный запрос к площадке.
5. `REVIEW_ALGORITHM_VERSION` → `search-review-v8`: вердикты планов без этих
   объектов пересматриваются.

## Результат

| Профиль | Заголовок | Было | Стало |
|---|---|---|---|
| поставка насосов | Насос центробежный | discard | match |
| поставка насосов | Поставка компрессоров | review | discard |
| монтаж КТП | Монтаж котла | review | discard |
| монтаж КТП | Монтаж КТП на объекте | review | match |

## Тесты

- «поставка насосов» → `objects: [насосов]`, desired содержит фразу и
  глагол;
- «Насос центробежный» → match, «Поставка компрессоров» → не match;
- «монтаж КТП» → `objects: [КТП]`;
- «Монтаж котла» → discard предметно, «Монтаж КТП на объекте» → match;
- всё без LLM и без отраслевых `if` — только лексиконы действий и форма
  объекта.

## Приёмка

- Насосы, КТП, НКУ и другие короткие обозначения остаются объектами.
- Чужой предмет работ отсекается `discard`, а не висит в `review` по общему
  глаголу.
- Evaluation: P/R/F1 = 100 %, FP=0, FN=0 — без регрессий.

## Риски и ограничения

- Объекты purchase-планов становятся дополнительными поисковыми термами
  (`platformSearchTerms`) — retrieval расширяется на слово-объект.
- Строчный объект из 2–3 букв по-прежнему отбрасывается («поставка газ» →
  без объекта) — осознанный консерватизм против мусорных обрывков; если
  понадобится, нужен словарь коротких имён, а не снижение порога.
- Действие по-прежнему не привязывается к конкретному объекту внутри
  заголовка — «Поставка крепежа, включая монтаж НКУ» остаётся известным
  ограничением.
