# Этап 74 — «Мои закупки»: список, страницы и профили

## Цель

Плитки «Мои закупки» тянулись по высоте из‑за длинных заголовков и контактов:
неровная сетка и бесконечный вертикальный скролл. Специалисту удобнее
смотреть закупки по профилю и листать страницами.

## Решение

1. Вместо карточной сетки — компактные строки одной ширины: заголовок до
   двух строк, вид/сумма/срок в одной полосе, заказчик в одну строку.
2. Пагинация по 12 строк, счётчик «N–M из K», кнопки «Назад» / «Вперёд» и
   номера страниц; при смене страницы список слегка появляется сверху.
3. Фильтр «Профиль»: «Все закупки» и по одному чипу на каждый профиль
   кабинета. В режиме «Все» на строке виден значок профиля.
