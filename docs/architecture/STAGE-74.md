# Этап 74 — «Мои закупки»: карточки без растяжения, страницы и профили

## Цель

Плитки «Мои закупки» тянулись по высоте из‑за длинных заголовков и контактов:
неровная сетка и бесконечный вертикальный скролл. Список строками специалисту
не понравился — нужны карточки, но ровные, с пагинацией и фильтром по профилю.

## Решение

1. Карточная сетка остаётся. Заголовок обрезается до 3 строк (одинаковая
   высота блока), заказчик до 2 строк, контакты с плитки убраны — детали в
   карточке закупки. Вид / сумма / срок — компактная полоса фактов.
2. Пагинация по 9 карточек, счётчик «N–M из K», «Назад» / «Вперёд» и номера;
   при смене страницы сетка мягко появляется.
3. Фильтр «Профиль»: «Все закупки» и чип на каждый профиль. В режиме «Все»
   на карточке виден значок профиля.
