# Этап 74 — «Мои закупки»: карточки, страницы и профили

## Цель

Бесконечный скролл и узкие «тянущиеся» плитки мешали разбирать кабинет.
Список строками не подошёл. Нужны карточки с полным заголовком, видом
процедуры, заказчиком и контактами, плюс пагинация и фильтр по профилю.

## Решение

1. Карточная сетка: полный заголовок без обрезки, блок заказчика и
   контактного лица/телефонов с площадки, поле «Вид процедуры» целиком.
   Отдельная ссылка «Открыть карточку» не нужна — открытие по клику на плитку.
2. Пагинация по 9 карточек, счётчик «N–M из K», «Назад» / «Вперёд» и номера;
   при смене страницы сетка мягко появляется. Высота карточек в ряду может
   отличаться — полный текст важнее выравнивания.
3. Фильтр «Профиль»: «Все закупки» и чип на каждый профиль.
