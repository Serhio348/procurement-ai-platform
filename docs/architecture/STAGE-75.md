# Этап 75 — upsert вердиктов поиска без 23505

## Цель

При сохранении профиля PostgreSQL падал с
`workspace_review_verdicts_uq` (23505): параллельный проход поиска и правка
профиля (или дубликаты в массиве вердиктов) пытались вставить ту же пару
`(workspace, profile, source)`. Диск сохранялся, SQL — нет; специалист
видел «не удалось записать профиль».

## Решение

1. Перед записью вердикты дедуплицируются по `profileId` +
   `sourceProcurementId` (оставляем более свежий `decidedAt`).
2. `INSERT … ON CONFLICT DO UPDATE` по уникальному индексу, даже если
   `DELETE` в той же транзакции гоняется с другим сохранением.
3. Сохранения кабинета (профиль / кейсы / inbox) идут в одну очередь на
   `workspaceId`, чтобы два писателя не дедлочили и не гоняли вердикты.
