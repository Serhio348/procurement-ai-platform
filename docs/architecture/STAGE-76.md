# Этап 76 — заголовок карточки: обрезка, hover и ровная сетка

## Цель

Полные длинные названия снова «рвали» высоту плиток. Нужно урезать только
слишком длинный заголовок, по наведению показать его целиком с лёгкой
анимацией, и выровнять карточки в ряду.

## Решение

1. Заголовок — до 3 строк (`line-clamp`), блок фиксированной минимальной
   высоты.
2. При наведении / фокусе поверх появляется полное название (fade + лёгкий
   подъём); карточка временно `overflow: visible` и выше соседей.
3. Сетка `align-items: stretch`, карточки одной высоты в ряду; заказчик и
   контакт тоже с мягким clamp, блок покупателя прижат вниз.
