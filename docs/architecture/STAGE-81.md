# Этап 81 — порт дизайна «Мои закупки» и видов процедур из ветки Cursor

## Цель

Дизайн карточек «Мои закупки» лежал в побочной ветке
`origin/cursor/mine-card-title-hover-f7ab` и расходился с main по общим
файлам (`specialist-store.ts`, `ProcurementsApp.tsx`, `styles.css`).
Вместо rebase ветки целиком дизайн перенесён точечно на текущий main.

## Что перенесено

Cherry-pick в порядке зависимостей (`70bfc8a → 496801b → c259f02 →
a69ef54 → fafa913 → c2492d2 → 3b257d0`), с разрешением конфликтов в
пользу новых путей записи/поиска:

- **«Мои закупки» как постраничный список карточек** — 12 на страницу,
  фильтр по профилю («Все закупки»/конкретный профиль), плитки одной
  высоты, полный текст карточки без отдельной ссылки «Открыть».
- **Длинные заголовки** — clamp на плитке, полный текст по hover.
- **«Вид процедуры» на карточке** — verbatim-текст поля «Вид процедуры
  закупки» с площадки (`SearchHit.kindLabel`, `rawFields`), fallback по
  семейству URL (`limited` → «конкурс с ограниченным участием»,
  `marketing` → «заявка о ценах (тарифах)», `etrade` → «открытый
  конкурс») вместо грубого «иная». Функции `cardProcedureKindLabel`,
  `printedProcedureKindLabel`, `procedureKindLabel` в
  `packages/domain/src/specialist/case.ts`.
- Парсер goszakupki.by сохраняет kind-метки с листинга и карточки.
